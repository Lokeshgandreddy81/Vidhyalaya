## 2024-08-07 - Sandbox Escape via Node.js VM Module
**Vulnerability:** Node.js `vm` module `runInNewContext` allows sandbox escapes if host objects (like `process: {}`) are injected. An attacker can use `process.env.constructor.constructor('return process')()` to walk up the prototype chain from the injected object, get the Function constructor of the main V8 context, and execute arbitrary code to gain full access to the host `process` object.
**Learning:** `vm.runInNewContext` is NOT a security mechanism by default. Simply omitting or redefining globals isn't enough if standard JavaScript objects created in the host context are passed into the sandbox. Their prototypes belong to the host context.
**Prevention:** Always use `vm.createContext` with `{ codeGeneration: { strings: false, wasm: false } }`. When injecting variables into the context, recursively create them using `Object.create(null)` to completely strip the prototype chain, preventing `.constructor` lookups from bridging the context boundary.
