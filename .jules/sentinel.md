## 2025-02-09 - Add SSRF Protection in AI Client Router
**Vulnerability:** The backend `aiClientRouter.js` accepted custom AI endpoints via the `x-byok-endpoint` header without verifying if the endpoint resolved to an internal, reserved, or loopback IP address (Server-Side Request Forgery).
**Learning:** Custom endpoints passed in request headers are untrusted user inputs. Without proper validation, an attacker could potentially scan internal network services or hit cloud metadata endpoints (like `169.254.169.254`). Validating custom endpoint hostnames by rejecting raw internal IP ranges isn't sufficient; DNS resolution (`dns.lookup`) must be explicitly executed to detect custom domains mapped to internal IPs. Furthermore, explicit protocol validation (e.g. `https:`) prevents basic bypasses.
**Prevention:** Always validate and sanitize user-provided URIs when making server-side fetch requests. Ensure protocols are restricted to `https:` and implement robust checks combining Regex constraints and `dns.lookup({ all: true })` to prevent DNS rebinding or external-to-internal resolution bypasses.
