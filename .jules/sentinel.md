## 2025-02-23 - Prevent SSRF Vulnerabilities in Custom AI Endpoints
**Vulnerability:** The AI client router (`aiClientRouter.js`) accepts custom REST endpoints via the `x-byok-endpoint` header for users providing their own models. Previously, this URL was directly passed to `fetch()`, allowing Server-Side Request Forgery (SSRF) against internal resources (e.g., `localhost`, `10.x.x.x`, `169.254.169.254`).
**Learning:** Node's built-in `URL` constructor automatically normalizes IP addresses. Obfuscated payloads (like decimal `2130706433` or octal `0177.0000.0000.0001`) evaluate to string representations like `127.0.0.1` on `url.hostname`. This makes it safe to apply regex IP validation without implementing complex custom deobfuscation logic.
**Prevention:** Always parse untrusted endpoint URLs through `new URL()`, extract the `hostname`, and explicitly validate against blocklists for loopback, private IPv4/IPv6, and cloud metadata addresses before making outbound requests.
