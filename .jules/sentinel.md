## 2025-02-14 - Prevent SSRF in AI Client Router (Custom Endpoints)
**Vulnerability:** The AI client router allows arbitrary, unvalidated custom endpoints (e.g., `x-byok-endpoint` headers) which can be routed to internal or loopback addresses, leading to a Server-Side Request Forgery (SSRF) vulnerability. This is especially dangerous since standard IPv4 mapped IPv6 and specific subnets are not systematically blocked by default in basic Node.js DNS/HTTP calls without explicit validation logic.
**Learning:** We must perform rigorous parsing of URL inputs to block not just `localhost` and `127.0.0.1`, but also alternative loopback representations (like IPv6 `::ffff:127.0.0.1`), metadata IP endpoints (`169.254.169.254`), and perform DNS lookups to catch custom domains that resolve to internal IPs (to prevent DNS rebinding or simple hiding techniques).
**Prevention:** Always validate custom user-supplied endpoint URLs for HTTPS and ensure that their raw hostname and their resolved IP addresses (using `dns.lookup` with `{ all: true }`) do not fall into private, internal, or loopback ranges before dispatching HTTP requests to them.
