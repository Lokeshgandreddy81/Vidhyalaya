## 2025-03-01 - [Node.js VM Sandbox Escape via Prototype Traversal]
**Vulnerability:** A sandbox escape was possible in `executeSanitizedUserCode` within `backend/src/utils/codeRunner.js` because standard JavaScript objects were used to mask system variables. Specifically, although `process` and `process.env` were masked, they retained the default Object prototype, allowing malicious user code to access `process.env.constructor.constructor('return process')()` and traverse back to the host Node.js global environment.
**Learning:** Initializing VM execution contexts with `{}` or passing standard host-created structures allows sandbox code to follow prototype chains directly to host context components (like the Function constructor).
**Prevention:** To prevent Node.js VM escapes, use `Object.create(null)` recursively for ALL sandbox context objects, avoid passing host-created functions, and apply `codeGeneration: { strings: false, wasm: false }` to the VM context configuration.
