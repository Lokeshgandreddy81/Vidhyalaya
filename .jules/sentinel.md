## 2024-05-18 - Fix VM Sandbox Escape via Prototype Chain Traversal
**Vulnerability:** The `executeSanitizedUserCode` function in `codeRunner.js` used `runInNewContext` and injected a host function (`process.exit`). This allowed malicious code to traverse the prototype chain (`process.exit.constructor('return process')()`) to escape the sandbox and access the host environment's `process` object, potentially leading to arbitrary code execution.
**Learning:** Using `runInNewContext` or even `createContext` with a plain object allows escape if ANY host-created function is injected into the context, because the function retains access to `Function.prototype` and its constructor chain from the host realm.
**Prevention:** Always use `vm.createContext` combined with `vm.runInContext`. Ensure all nested context objects are created using `Object.create(null)` to eliminate prototypes, completely avoid injecting host functions, and use `codeGeneration: { strings: false, wasm: false }` to prevent dynamic evaluation.
