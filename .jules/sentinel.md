## 2024-05-24 - Node.js VM Sandbox Escape via Prototype Chain
**Vulnerability:** The code runner utility `executeSanitizedUserCode` used `vm.runInNewContext` with a plain Javascript object literal as the sandbox context, and injected host objects (like `process.env`).
**Learning:** In Node.js, objects created via object literals inherit from `Object.prototype` of the host environment. This allows untrusted scripts executed within the VM to traverse the prototype chain (e.g., `this.process.env.constructor.constructor('return process')()`) to gain access to the host's global context, escaping the sandbox completely and allowing arbitrary code execution or access to environment variables.
**Prevention:** Always initialize VM contexts using `Object.create(null)` to ensure the sandbox has a null prototype. Ensure all injected nested objects are also created with a null prototype. Use `vm.createContext` and configure `codeGeneration: { strings: false, wasm: false }` to disable dynamic code generation, and execute the script using `vm.runInContext`. Avoid injecting any functions created in the host context into the sandbox.
