## 2024-07-14 - Fix VM Sandbox Escape Vulnerability
**Vulnerability:** Node.js `vm` module `runInNewContext` sandbox escape via host objects. The application passed a host object (`process: { exit: () => {} }`) to the sandbox context. An attacker could escape the sandbox by walking the prototype chain of these injected host objects (e.g., `this.process.exit.constructor.constructor("return process")().env`), thereby gaining access to the host `process` object and potentially remote code execution.
**Learning:** Passing any host objects (like functions or objects) into a `vm` sandbox allows the sandboxed code to traverse the prototype chain back to the host environment, completely bypassing the sandbox isolation. Creating the sandbox context with `Object.create(null)` is not sufficient if host objects are still passed into it.
**Prevention:** Always use `Object.create(null)` for the sandbox context and NEVER pass any host functions or complex objects into the sandbox context. If host interaction is necessary, use a more secure sandboxing library like `isolated-vm` which provides proper memory and context isolation.
