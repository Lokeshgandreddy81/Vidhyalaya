## 2024-07-01 - Prevent SSRF in AI Client Router
**Vulnerability:** The `aiClientRouter.js` script accepted a `x-byok-endpoint` custom endpoint from request headers to allow arbitrary LLM endpoints for users. This URL was passed directly into `fetch()`, introducing a Server-Side Request Forgery (SSRF) vulnerability. This would allow an attacker to send HTTP requests to internal IP addresses (e.g. `127.0.0.1`, `169.254.169.254`).
**Learning:** Custom endpoints need rigid verification before proxying them to internal infrastructure or resolving. Standard hostname string checks are insufficient to block all forms of bypassing (like IPv6 variants or DNS rebinding where a domain resolves to an internal IP).
**Prevention:** Always validate user-provided URLs. Use `dns.promises.lookup` (with `all: true`) on the extracted hostname (stripping IPv6 brackets first) to resolve all underlying IPs and block internal, loopback, or private ranges before passing the URL to `fetch()`. Enforce `https:` protocol and block direct IP requests to known private spaces.
