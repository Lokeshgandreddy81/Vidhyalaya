## 2024-10-25 - VM Sandbox Escape via Injected Host Functions
**Vulnerability:** The `executeSanitizedUserCode` function in `backend/src/utils/codeRunner.js` passed a host-created arrow function (`process.exit = () => { ... }`) directly into the `node:vm` sandbox context.
**Learning:** Injecting any host object, especially functions, into a Node.js `vm` sandbox leaks the host's `Function.prototype` or `Object.prototype`. Malicious user code can traverse the constructor chain (e.g., `process.exit.constructor("return process")()`) to escape the sandbox and execute arbitrary commands on the host system, leading to Remote Code Execution (RCE).
**Prevention:** Always initialize VM contexts using `vm.createContext()` instead of passing objects directly to `runInNewContext()`. Ensure every object injected is created with a `null` prototype (`Object.create(null)`). Never pass host functions; pass raw primitive data instead, and always disable code generation using `codeGeneration: { strings: false, wasm: false }`.
