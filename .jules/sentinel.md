## 2024-05-24 - [CRITICAL] Fix SSRF in AI Client Router Custom Endpoints
**Vulnerability:** The `aiClientRouter.js` supported custom model endpoints (`x-byok-endpoint` headers) but blindly passed these URIs into `fetch()` calls. This allowed Server-Side Request Forgery (SSRF) against internal services (e.g. `localhost`, `10.x.x.x`), and DNS rebinding attacks to resolve external domains to internal metadata services.
**Learning:** Standard naive string filtering for SSRF fails against IPv4-mapped IPv6 obfuscation (e.g., `[::ffff:127.0.0.1]`) which the native Node.js `URL` object preserves. Validating DNS is also essential to prevent malicious external domains from resolving to local network addresses.
**Prevention:** Implement strict network-level validations before HTTP calls: enforce HTTPS, validate against a comprehensive internal subnet blocklist (including link-local and obfuscated IPv6), and execute DNS lookups that aggressively reject resolving to internal IPs, while deliberately propagating DNS errors to thwart Time-of-Check to Time-of-Use (TOCTOU) exploits.
