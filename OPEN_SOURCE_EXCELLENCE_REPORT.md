## 2. Problems Found & Improvements Made

### A. Root Directory Sprawl
*   **Problem**: The root directory was cluttered with 58 raw markdown audit reports generated by previous development sessions, creating noise and poor developer discoverability.
*   **Improvement**: Created the [docs/audits/](file:///Users/lokeshgandreddy/Sara/Vidhyalaya/docs/audits/) directory and consolidated all 58 audit reports inside it. The repository root now contains only standard project configuration and maintainer guides.

### B. Developer Onboarding & Contribution Guides
*   **Problem**: No contribution guidelines, branching explanations, or setup checklists existed in the repository.
*   **Improvement**: Developed the official contribution guide: [CONTRIBUTING.md](file:///Users/lokeshgandreddy/Sara/Vidhyalaya/CONTRIBUTING.md).

### C. Missing CI/CD Automated Pipelines
*   **Problem**: No lint, build, or test validation checks were configured, leaving the repository vulnerable to syntax errors or compilation regressions.
*   **Improvement**: Designed and implemented the GitHub Actions pipeline: [.github/workflows/ci.yml](file:///Users/lokeshgandreddy/Sara/Vidhyalaya/.github/workflows/ci.yml). This pipeline automatically checks code quality on pushes and PRs.

### D. Standardized Pull Request & Issue Templates
*   **Problem**: External contributors lacked unified forms to report bugs, suggest features, or submit pull requests, leading to inconsistent issues.
*   **Improvement**: Created:
    - PR Template: [.github/pull_request_template.md](file:///Users/lokeshgandreddy/Sara/Vidhyalaya/.github/pull_request_template.md)
    - Bug Issue Template: [.github/ISSUE_TEMPLATE/bug_report.md](file:///Users/lokeshgandreddy/Sara/Vidhyalaya/.github/ISSUE_TEMPLATE/bug_report.md)
    - Feature Request Template: [.github/ISSUE_TEMPLATE/feature_request.md](file:///Users/lokeshgandreddy/Sara/Vidhyalaya/.github/ISSUE_TEMPLATE/feature_request.md)

## 4. Remaining Technical Debt & Code Quality Refactoring

The following monolithic files remain in the codebase and are primary candidates for future modularization:

1.  **`StudySession.tsx` (177 KB)**:
    - *Issue*: Massive monolithic design coupling state tracking, sidebar navigations, Web Speech API voices, drawing canvas context, and UI layouts.
    - *Refactoring Recommendation*: Extract the audio soundscapes and speech synthesis logic into custom hooks (`useSpeechSynthesis`, `useWebAudioSoundscapes`). Separate the split-pane layouts into dedicated sub-components.
2.  **`CodeSandbox.tsx` (130 KB)**:
    - *Issue*: Combines code editing, layout rendering, iframe execution, and a virtual folder navigation tree.
    - *Refactoring Recommendation*: Separate the virtual filesystem UI and code file tree explorer component from the actual sandbox compilation panel.
